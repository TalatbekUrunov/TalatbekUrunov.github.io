Code execution

2 findings
gray-matterCriticalCVSS 9.8CVE pending

Front-matter language is auto-detected from untrusted input and routed to an eval engine. A markdown document beginning ---js executes arbitrary JavaScript in the host process — no application opt-in required. Full remote code execution from user-submitted content.

ClassCWE-94 · Code Injection
Sinkmatter() → eval()
Affected≤ 4.0.3 (latest)
Downloads~30M / mo
▶Proof of concept & fix
// a document whose ---js front-matter runs on parse const matter = require('gray-matter'); matter('---js\n((function(){ return process.pid })())\n---'); // the front-matter body is handed straight to eval() — arbitrary JS executes
FixNever route untrusted front-matter through eval. Disable the js engine unless the host explicitly opts in, and document that ---js is code execution, not data.
yaml-front-matterHighCVSS 8.1CVE pending

The primary loadFront() API parses front-matter with js-yaml's unsafe full schema, enabling the !!js/function tag. Untrusted front-matter deserializes into callable JavaScript functions — code execution when the application invokes a front-matter value.

ClassCWE-502 · Deserialization
SinkloadFront() → yaml.load
Affected≤ 4.1.1 (latest)
Downloads~353K / mo
▶Proof of concept & fix
// !!js/function is honoured by the unsafe full schema const { loadFront } = require('yaml-front-matter'); const doc = loadFront('---\nfn: !!js/function "function(){ return 42 }"\n---'); doc.fn(); // => 42 — deserialized straight into a callable function
FixParse with js-yaml's DEFAULT_SAFE_SCHEMA (safeLoad) instead of the full schema, so !!js/function and other code-bearing tags are rejected.

Regular expression denial of service

6 findings
strip-commentsMediumCVSS 5.3CVE pending

Exponential backtracking in the quoted-string regex (a latent [^\1] class bug). A ~65-byte input freezes the Node.js event loop for ~39 seconds; a few more bytes never returns.

ComplexityO(2ⁿ) exponential
Functionstrip()
Affected≤ 2.0.1 (latest)
Downloads~36M / mo
▶Proof of concept & fix
const strip = require('strip-comments'); // ~65 bytes of unterminated quoted content — event loop frozen ~39 s strip('/*' + '"'.repeat(30) + '!'); // a few more chars and the call never returns
FixReplace the catastrophic [^\1]-style class in the quoted-string pattern with an explicit, non-backtracking scanner (or an atomic group), so match time stays linear in input length.
platform (platform.js)MediumCVSS 5.3CVE pending

Quadratic backtracking in the Android User-Agent regex of parse(). A crafted ~720 KB User-Agent blocks the event loop for ~22 seconds; reachable wherever User-Agent strings are parsed.

ComplexityO(n²) quadratic
Functionparse(ua)
Affected≤ 1.3.6 (latest)
Downloads~25M / mo
▶Proof of concept & fix
const platform = require('platform'); // crafted Android User-Agent, ~720 KB — event loop frozen ~22 s const ua = 'Mozilla/5.0 (Linux; Android ' + ' '.repeat(720000) + ';)'; platform.parse(ua); // reachable anywhere a UA header is parsed
FixAnchor and bound the Android segment of the UA regex (cap the repeated group), or pre-truncate User-Agent input to a sane length before parsing.
semver-utilsMediumCVSS 5.3CVE pending

Cubic backtracking in parseRange() on a run of whitespace. ~4 KB of spaces blocks the event loop for ~19 seconds; a small payload for a large stall.

ComplexityO(n³) cubic
FunctionparseRange()
Affected≤ 1.1.4 (latest)
Downloads~2M / mo
▶Proof of concept & fix
const semverUtils = require('semver-utils'); // ~4 KB of whitespace — three nested optional groups → cubic blow-up, ~19 s semverUtils.parseRange(' '.repeat(4000) + '!');
FixCollapse leading/trailing whitespace before matching, and flatten the nested optional groups so the range pattern can't backtrack cubically.
underscore.stringMediumCVSS 5.3CVE pending

Quadratic backtracking in stripTags() on unclosed < characters. Distinct from the earlier unescapeHTML issue (CVE-2017-16116) and unpatched in the latest release.

ComplexityO(n²) quadratic
FunctionstripTags()
Affected≤ 3.3.6 (latest)
Downloads~4M / mo
▶Proof of concept & fix
const s = require('underscore.string'); // a long run of unclosed '<' — quadratic backtracking in the tag regex s.stripTags('<'.repeat(160000)); // ~11.5 s for ~160 K chars
FixMatch tags with a tempered pattern (<[^>]*>) or a single linear scan instead of a backtracking greedy group — and note this is distinct from CVE-2017-16116 (unescapeHTML), still unpatched.
auth-headerMediumCVSS 5.3CVE pending

Quadratic backtracking while tokenizing HTTP Authorization / WWW-Authenticate headers. A ~160 KB header of space-separated tokens blocks the event loop for ~26 seconds.

ComplexityO(n²) quadratic
Functionparse(header)
Affected≤ 1.0.0 (latest)
Downloads~530K / mo
▶Proof of concept & fix
const auth = require('auth-header'); // ~160 KB Authorization header of space-separated tokens — ~26 s auth.parse('Bearer ' + 'a '.repeat(80000));
FixTokenize the header with a linear split rather than a backtracking regex, and cap header length before parsing (attacker controls the Authorization / WWW-Authenticate value).
configparserMediumCVSS 5.3CVE pending

Polynomial backtracking in read() on a whitespace-heavy configuration line. An ~8 KB line blocks the event loop for ~88 seconds; reachable via attacker-controlled config files.

ComplexityO(n³) polynomial
Functionread(file)
Affected≤ 0.3.10 (latest)
Downloads~132K / mo
▶Proof of concept & fix
const { ConfigParser } = require('configparser'); // a single ~8 KB whitespace-heavy line freezes read() for ~88 s fs.writeFileSync('evil.ini', '[s]\nk =' + ' '.repeat(8000) + '!'); new ConfigParser().read('evil.ini'); // reachable via attacker-supplied config
FixTrim each line before applying the key/value pattern, and rewrite the section/option regex so the whitespace groups can't overlap and backtrack.
